Self-hosted typefaces for the Seastones Rig page (DESIGN-SYSTEM 3, KIOSK-6).

The station is offline and the page makes no external request; these files are why.
Licence for all four families: SIL Open Font License 1.1 (OFL), https://openfontlicense.org
CT-12 (THIRD-PARTY-NOTICES) must list them.

  Roboto Slab ExtraBold 800  Christian Robertson, Google. OFL 1.1. Display role.
  Oswald                     Vernon Adams, Kalapi Gajjar, Cyreal. OFL 1.1. Label role.
  IBM Plex Sans              Mike Abbink, Bold Monday, for IBM. OFL 1.1. Body role.
  JetBrains Mono             JetBrains s.r.o. OFL 1.1. Mono role.

Latin subsets. Oswald, IBM Plex Sans and JetBrains Mono are byte-identical to the Model 4
kiosk's src/web/assets/fonts/ (so one fonts folder serves the museum); Roboto Slab was
fetched on 2026-10-31 from Google Fonts.
